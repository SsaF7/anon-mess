# anon-mess
Анонимный месседжер на Python

P2P: отдельного сервера нет, каждый участник запускает один и тот же файл.

## Запуск

```
python3 mess_peer.py
```

1. Введите имя и порт, на котором ваш узел будет принимать подключения.
2. Введите `ip:port` любого участника, который уже в сети.
   Если вы первый — оставьте пустым.

Узлы обмениваются списками участников и сами подключаются друг к другу,
поэтому достаточно знать адрес одного из них. Сообщения пересылаются
по сети дальше, так что доходят даже до тех, с кем нет прямого соединения.

Команды: `/peers` — список подключённых участников, `/quit` — выход.

## Ограничения

- Чтобы к вам могли подключиться из интернета, порт должен быть открыт
  (проброс порта на роутере). В локальной сети работает сразу.
- Сообщения не шифруются.
